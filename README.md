# Spots — public support pages

Public support and legal pages for Spots, provided by Dakoty Studio s. r. o.

Published at https://marosluk.github.io/spots-support/

Generated from the canonical app legal pages. This repository contains only static public content, not the application, accounts or credentials. GitHub Pages serves main / (root); HTTPS enabled.

To update: run `node infrastructure/github-pages/build.cjs <output-directory>` in the private Spots source repository, review the generated output, then commit and push it here.
